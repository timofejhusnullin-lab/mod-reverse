# Time Rewind — мод для Minecraft 26.3 (Fabric)

Зажми **Z** — время идёт назад. Отпусти — отмотка останавливается и игра продолжается с этого момента.

## Что откатывается
- Игрок: позиция, взгляд, скорость, здоровье, еда, огонь, воздух, высота падения
- Мобы в радиусе 32 блоков (позиция и здоровье), если они ещё живы
- Во время отмотки ты неуязвим

## Смерть
Если ты должен был умереть, смерть откладывается на 6 секунд. Над хотбаром появится подсказка. Успей зажать Z — и вернёшься назад. Не успел — умираешь по-настоящему. Если история пуста (только зашёл в мир), откатывать нечего и смерть обычная.

## Что НЕ откатывается
Блоки, выпавшие предметы, инвентарь, эффекты зелий, погода и время суток, убитые мобы.

## Настройки
Всё в начале `src/main/java/com/timerewind/RewindManager.java`: длина истории (30 с), скорость отмотки (x2), радиус мобов, время на спасение (6 с). Клавишу можно сменить в настройках управления (категория Time Rewind).

## Установка
Нужны Minecraft **26.3**, Fabric Loader **0.20.1+**, **Fabric API** и Java **25**.
Положи `timerewind-1.1.0.jar` и Fabric API в папку `mods`. Мод нужен и на сервере, и на клиенте (в одиночной игре — просто в `mods`).

## Сборка
Нужен JDK 25.

    ./gradlew build

Готовый jar: `build/libs/timerewind-1.1.0.jar`.

Без установки JDK: залей папку в репозиторий на GitHub. Workflow `.github/workflows/build.yml` соберёт jar сам, он будет во вкладке Actions в артефактах.
